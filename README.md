# first-time

사용자 얼굴 사진을 배경으로 사용하는 1인용 **Face Breakout** 게임입니다.

## 게임 컨셉

- 시작 시 `3, 2, 1` 카운트다운 후 눈을 깜빡이며 검은 볼 2개가 양쪽 눈에서 생성됩니다.
- 플레이어는 **아랫입술 패들**을 좌우로 움직여 볼이 바닥으로 떨어지지 않게 튕깁니다.
- 볼이 특정 구멍(콧구멍/귓구멍/눈동자/이마)에 들어가면 해당 부위에 털이 자라납니다.
- 볼이 모두 사라지면 다시 눈을 깜빡이며 다음 라운드 볼이 생성됩니다.
- 라운드가 진행될수록 Level 1 → 2 → 3으로 난이도가 올라갑니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 조작

- 아랫입술 패들 이동: `← / →` 또는 `A / D`
- 마우스 이동으로도 패들 위치 조절 가능
- `다시 시작` 버튼으로 초기화
- `배경 사진 선택` 입력으로 원하는 얼굴 사진 업로드
