# first-time

고전 게임 **퐁(Pong)** 을 브라우저에서 실행할 수 있는 간단한 프로젝트입니다.

## 실행 방법

별도 의존성 없이 정적 파일만으로 동작합니다.

1. 저장소 루트에서 `index.html` 파일을 브라우저로 엽니다.
2. 또는 간단한 서버를 띄워 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 조작키

- 왼쪽 패들: `W` / `S`
- 오른쪽 패들: `↑` / `↓`
- 일시정지/재개: `Space`
- 재시작: `다시 시작` 버튼
