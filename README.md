# first-time

첨부한 얼굴 사진을 고정 배경으로 사용하는 1인용 **Face Breakout** 게임입니다.

## 핵심 규칙

- 시작 시 `3, 2, 1` 카운트다운 후 눈 깜빡임 연출과 함께 검은 공 2개가 양쪽 눈에서 생성됩니다.
- 플레이어는 **아랫입술 패들**을 좌우 이동해 공을 튕깁니다.
- 공이 얼굴 구멍에 들어가면 해당 위치에서 털이 3초 동안 한 가닥씩 길게 자랍니다.
- 공이 구멍에 들어가거나 바닥으로 떨어져 공이 모두 사라지면 다시 눈을 깜빡이며 공이 재생성됩니다.
- 라운드가 진행되면 Level 1 → Level 2 → Level 3으로 속도가 증가합니다.

## 구멍 위치/효과

- 눈 구멍 2개 → 눈썹 성장
- 코 구멍 2개 → 콧털 성장
- 입술 중앙 구멍 1개 → 수염 성장
- 귀 구멍 2개 → 속눈썹 성장
- 이마 중앙 구멍 1개 → 머리카락 성장

## 사운드

- 입술 패들 반사 시 효과음
- 구멍 진입 시 효과음

## 실행 방법

1. 프로젝트 루트에 배경 파일을 `face-fixed.jpg` 이름으로 둡니다.
2. 아래 명령 실행:

```bash
python3 -m http.server 8000
```

3. 브라우저에서 `http://localhost:8000` 접속

## 조작

- 패들 이동: `← / →` 또는 `A / D`
- 마우스로도 패들 이동 가능
- `다시 시작` 버튼으로 리셋
